## Description
**SO_LONG** 
This project is a small 2D game. Its purpose is to have you work with textures, sprites, and other basic gameplay elements.

## Instruction

### Usage
#### Compilation
The project includes a `Makefile` that compiles the source files into an executable named `so_long`. To compile, run:
```bash
make

```
#### Cleanup
To remove object files, run:
```bash
make fclean
```
